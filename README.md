# Interior Design Skills

Agent skills for interior design practice, mapped 1:1 to the **Interior Skills** folder in the Postman collection [Interior Design Skills Discovery](https://suhascrazy45-6027490.postman.co/workspace/006cdfa7-a57f-412b-84bd-1a59a15c76f8/collection/52494920-c2a928b1-ad55-4465-b65e-a7a7c5a0e667).

Postman’s folder held discovery **requests**. This repo holds the actual **skills** (`SKILL.md`) you can install in Cursor / Codex-compatible agents.

## Install (Cursor)

Copy any skill folder into `~/.cursor/skills/` or a project’s `.cursor/skills/`:

```bash
cp -R skills/03-programming-space-planning ~/.cursor/skills/programming-space-planning
```

Or clone and point your agent at `skills/`.
