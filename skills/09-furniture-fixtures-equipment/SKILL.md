# Furniture, Fixtures, and Equipment (FFE)

Specify FF&E that fits the body, the room, and the budget.

## Method
1. Confirm activities and storage needs
2. Size pieces to room and circulation (include critical dimensions)
3. Balance fixed vs flexible furniture
4. Align finishes with the material palette
5. Note lead times, alternatives, and phase-able purchases

## Output format
For each item: name/type, approx. size, placement rationale, finish, qty, priority (must/should/nice), and open questions (power, blocking, code).

## Boundaries
Concept-level specification only unless the user provides cut sheets; recommend verifying manufacturer data and local code for built-ins and fixed fixtures.
