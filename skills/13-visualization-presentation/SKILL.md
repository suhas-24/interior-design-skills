# Visualization and Presentation

Sell the idea clearly. One story per view.

## Presentation structure
1. Problem / brief
2. Concept direction
3. Plan/zoning
4. Key perspectives
5. Palette & materials
6. Next decisions needed from the client

## Image prompts (when generating)
Preserve architecture unless construction changes are requested. Include: style, room type, layout/focal point, materials, palette, lighting, mood, camera/view, photorealistic interior photography.

## Rules
Generate options that change one or two variables at a time. Never imply a render proves dimensions, products, or code compliance.
