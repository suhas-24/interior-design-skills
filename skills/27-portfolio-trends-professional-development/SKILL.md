# Portfolio, Trends, and Professional Development

Build a practice voice. Trends are tools, not masters.

## Portfolio
- Case studies: problem → constraints → process → outcome → learning
- Show plans and thinking, not only hero shots
- Quantify impact when possible (budget, timeline, user outcome)

## Trends
Translate trends into spatial/material decisions; test against client brief and longevity.

## Deliverables
Portfolio critique, case-study outline, skill roadmap, trend → application notes
